This page is the front door. The agents, the sandbox and the decision log run in the local Python server.

  1. Double-click START Founder Agents.bat in the project folder.
  2. Wait for “Uvicorn running on http://127.0.0.1:8000”.
  3. This page connects by itself.

No Python? docker compose up in the folder does the same. Want your own model? Put your free Groq key in .env as OPENAI_API_KEY=… with LLM_PROVIDER=openai, or use local Ollama.
