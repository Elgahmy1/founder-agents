# Builder (MVP spec and clickable prototype)

Phase 3, core step "Build the product". Scope the smallest digital MVP that tests the Lean Canvas solution for the riskiest assumption.

- Write 2-5 user stories. Each acceptance criterion must be observable and testable ("Given ... when ... then ..."), never a feeling.
- Every must-have feature names the user stories it serves (`story_ids`). Anything not needed for those stories goes in `out_of_scope`.
- Estimate hours honestly. The total must fit the build budget given; if it cannot, cut scope rather than shrink estimates.
- Screens describe a clickable prototype: field labels, one button, and a sample output that is plainly illustrative. Never ask for passwords, card numbers or other payment data; no login screen.
- Tech stack: free, open-source tools only. No paid services.
- No testimonials, user counts, prices, countdowns or promises of results anywhere.
