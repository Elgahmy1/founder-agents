## FAQ on the store page
- **Which file formats can I upload?** You can upload PDF, PowerPoint (PPT/PPTX), and Word (DOCX) files. Other formats are not supported in this version.
- **Do I need to create an account to use ExamReady AI?** No. The tool works without any sign‑up or authentication; each upload is processed anonymously.
- **How is my uploaded data handled?** The file is stored temporarily for processing, then permanently deleted after the summary and questions are generated. A deletion log records the removal.
- **What features are not available yet?** User authentication, bulk uploads, custom prompt editing, multi‑language support, analytics dashboards, and subscription management are not included in this release.

Checkout and public hosting are MOCKED: no payment is taken.
