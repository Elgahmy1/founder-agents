ExamReady AI

Product vision: Upload lecture PDFs/slides and instantly get concise exam‑ready summaries and practice questions.

User guide: what this MVP does today, how to use it, and what it does not do yet.

What this MVP does today: paste text, press Run, and it shows the result of generate_summary and generate_questions on your text.

As Student who has lecture PDFs, I want to upload the file and receive a concise summary, so that I can study the key points quickly.

MVP built by Founder Agents from code that passed 3/3 acceptance checks. Each request runs generate_summary(text), generate_questions(text) in an isolated sandbox with no file, network or process access. Nothing you paste is stored. Accounts, storage and public hosting are not part of this MVP.
