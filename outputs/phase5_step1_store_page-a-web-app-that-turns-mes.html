Questions

What does each plan include?
Free: free (File Upload & Processing, Summary Generation, Result Display & Download, Automatic Data Deletion, Practice Question Generation); Pro: 9.99 USD / month (File Upload & Processing, Summary Generation, Result Display & Download, Automatic Data Deletion, Practice Question Generation). These are the plans the founder approved.
Which file formats can I upload?
You can upload PDF, PowerPoint (PPT/PPTX), and Word (DOCX) files. Other formats are not supported in this version.
Do I need to create an account to use ExamReady AI?
No. The tool works without any sign‑up or authentication; each upload is processed anonymously.
How is my uploaded data handled?
The file is stored temporarily for processing, then permanently deleted after the summary and questions are generated. A deletion log records the removal.
What features are not available yet?
User authentication, bulk uploads, custom prompt editing, multi‑language support, analytics dashboards, and subscription management are not included in this release.
