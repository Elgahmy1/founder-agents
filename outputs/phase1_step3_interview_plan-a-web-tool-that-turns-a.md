# Phase 1, step 3: Customer interviews (Mom Test)

Goal: Validate that Egyptian freelance developers spend significant time manually creating weekly progress reports for non‑technical clients and that they actively seek/try workarounds to reduce this friction.

## Who to talk to
- Freelance software developer based in Egypt
- Delivers client projects remotely
- Communicates progress to non‑technical clients on a weekly basis
- Uses a git repository (GitHub, GitLab, Bitbucket, etc.) for code versioning

## Questions (past behaviour, not opinions)
1. Can you walk me through the last time you had to send a weekly progress update to a client?
2. What steps did you take to gather the information for that update?
3. How did you turn your git commits and task notes into the final report?
4. How long did it take you from opening the repo to hitting send on the email?
5. What tools or scripts (if any) did you use to help with the summary?
6. Did you ever copy‑paste commit messages into ChatGPT, a template, or a custom script? What was that experience like?
7. What was the most frustrating part of creating that report?
8. Have you ever tried to automate the process (e.g., using a script, a third‑party AI, or a project‑management tool)? What did you end up doing?
9. Did you spend any money on a solution or on a paid AI plan to help with summarising?
10. After you finished the report, did you have to make any follow‑up clarifications with the client because the summary was unclear?

## Avoid
- Would you buy a tool that automatically generates a weekly summary?
- How much would you be willing to pay for such a product?
- Do you think an automated summary would be useful for you?
- If we built this, would you use it?
- Would you prefer English or Arabic reports?
- Do you like the idea of connecting your repo to an LLM?

Problem counts as confirmed if: The interviewee describes a specific recent weekly update (e.g., “last Thursday I spent 45 minutes drafting the email”) and mentions that they have already tried a workaround such as using ChatGPT, a manual template, or a custom script, or that they have spent money/time on a solution to reduce the effort.

## Outreach draft (queued for founder approval; the founder sends it personally)
